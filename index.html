Simulación de Bacterias con Fibonacci

Problema Cotidiano

Algunas bacterias pueden reproducirse rápidamente dependiendo del ambiente en el que se encuentren. Este proyecto utiliza la sucesión Fibonacci para simular el crecimiento bacteriano durante diferentes etapas o meses.

Aunque las bacterias reales no crecen exactamente siguiendo Fibonacci, esta simulación permite representar matemáticamente un crecimiento progresivo y comprender cómo las matemáticas y la programación ayudan a modelar fenómenos de la vida real.

Explicación del Proyecto

La sucesión Fibonacci consiste en sumar los dos números anteriores para generar el siguiente valor.

Ejemplo: 1, 1, 2, 3, 5, 8, 13...

En esta simulación cada número representa la cantidad de bacterias existentes en una etapa determinada.

Además, el usuario puede seleccionar diferentes ambientes para observar cómo las bacterias podrían reproducirse más rápido o más lento.

Explicación del Algoritmo

El algoritmo utilizado en este proyecto genera la sucesión Fibonacci para simular el crecimiento de una población de bacterias.

La lógica principal consiste en sumar los dos valores anteriores para obtener la siguiente cantidad de bacterias.

Ejemplo:

1, 1, 2, 3, 5, 8, 13...

Cada número representa la cantidad estimada de bacterias existentes en cada etapa o mes de crecimiento.

Además, el algoritmo utiliza distintos ambientes para modificar la velocidad de reproducción bacteriana.

  • 🔥 Ambiente cálido: crecimiento normal.
  • ❄️ Ambiente frío: crecimiento reducido.
  • ☢️ Ambiente contaminado: crecimiento alterado.
  • 🧪 Laboratorio: crecimiento acelerado.

El sistema multiplica los valores de Fibonacci según el ambiente seleccionado para representar distintos escenarios biológicos.

El algoritmo utiliza:

  • Variables let
  • Ciclos for
  • Condicionales if
  • Manipulación del DOM con getElementById

Gracias a esto, la página puede simular automáticamente el crecimiento bacteriano y mostrar resultados dinámicos en tiempo real.

Conclusión
